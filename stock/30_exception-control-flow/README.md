# 【ストック】検索条件パラメータの解釈処理

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

商品検索画面から送られてくるリクエストパラメータ（すべて文字列）を解釈して、検索条件オブジェクトを組み立てるクラスです。
ページ番号・価格の上限・区分コードといった文字列を数値に変換したり、区分コードの一覧から該当する区分を探したりして、
`SearchCondition` を作って返します。数字でないパラメータや、一覧に無い区分が来ることもあります。

対象: `bad/SearchParamParser.java`
「どこが問題か、どう直すべきか」をレビューしてみてください。
