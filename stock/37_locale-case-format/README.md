# 【ストック】商品コードの正規化と金額整形

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

ユーザーが画面から入力した商品コードを、大文字にそろえて（正規化して）社内マスタの値と照合したり、Mapのキーに使ったりするためのクラスです。あわせて、商品の金額を「小数2桁の文字列」に整形し、他システムへ渡すCSVなどの連携ファイルに書き出す処理も持っています。
このサービスは今は国内だけで動いていますが、将来は海外拠点のサーバーでも同じコードを動かす可能性がある、という前提で見てもらえると助かります。
