# 【ストック】割り勘・税込計算サービス

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

飲み会の割り勘や税込金額を計算する `BillingCalculator` です。
`perPerson()` は合計金額を人数で割った1人あたりの金額を、
`taxIncluded()` は本体価格に消費税（10%）を足した税込金額を返します。
金額の誤差を避けたいので、`double` ではなく `BigDecimal`（正確な十進計算ができる型）を
使っています。
