# 【ストック】会員一斉メールの並列送信

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

登録している全会員へ、お知らせメールを一斉配信するサービスです。1通ずつ順番に送っていると時間がかかりすぎるため、スレッド（＝並行して動く作業員）で手分けして同時に送り、処理を速くする狙いです。
会員は数万人規模になることもあり、キャンペーンのたびにこの `sendToAll` が呼び出されます。
「速く送れればよい」という発想で書かれたコードですが、本番で繰り返し呼ぶと少しずつ様子がおかしくなっていくようです。
