# 【ストック】注文ステータスのJPA保存

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

注文（Order）の状態を扱うサービスです。注文は状態を enum `OrderStatus`（NEW / PAID / SHIPPED / CANCELED）で持ち、
JPA でデータベースに永続化しています。サービスでは、指定した注文の状態を次の状態へ進める処理と、注文一覧を取得して返す処理を提供します。
今後、状態の種類（例：返品受付、保留 など）が増えていく想定です。
