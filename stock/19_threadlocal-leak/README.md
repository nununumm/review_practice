# 【ストック】マルチテナントのテナントID保持（ThreadLocal）

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

1つのシステムを複数の会社（テナント）で共有するマルチテナントなWebアプリです。
リクエストの入口で、今アクセス中のテナントID を `ThreadLocal`（＝スレッドごとに別々の値を持てる保管箱）に入れておき、
後続のレポート生成サービス（`ReportService`）がそこからテナントIDを取り出してデータを絞り込んでいます。

対象: `bad/TenantContext.java`（あわせて `bad/TenantFilter.java` / `bad/ReportService.java` も見てください）
「どこが問題か、どう直すべきか」をレビューしてみてください。
