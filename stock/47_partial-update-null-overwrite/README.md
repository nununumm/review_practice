# 【ストック】会員プロフィールの部分更新API

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

会員のプロフィール（ニックネーム・電話番号・メール・誕生日）を更新する
`MemberProfileService` です。画面の「プロフィール編集」から、変更したい項目だけを
送る **部分更新（PATCH）** を想定しています。`updateProfile()` はリクエスト
`ProfileUpdateRequest` を受け取り、会員を取得して各項目をセットし直して保存します。
リクエストには「今回変更したい項目だけ」が入り、変更しない項目は値が入っていません。

対象: `bad/MemberProfileService.java`
「どこが問題か、どう直すべきか」をレビューしてみてください。
