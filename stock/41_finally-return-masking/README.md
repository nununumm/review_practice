# 【ストック】設定ファイルからAPIキーを読み込むサービス

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

外部サービス連携用の API キーを、サーバー上の設定ファイル（プロパティファイル）から読み込む
`ConfigLoader` です。`loadApiKey()` で「ファイルを開く → プロパティを読む → `api.key` の値を返す」
という流れになっており、読み込みに使った `BufferedReader` は `finally` で閉じています。

対象: `bad/ConfigLoader.java`
「どこが問題か、どう直すべきか」をレビューしてみてください。
