# 【ストック】為替レート表の遅延初期化ホルダー

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

為替レート表（`RateTable`）を保持する `ExchangeRateHolder` です。レート表の生成はデータベースへの
問い合わせを伴い重いので、「最初に必要になったときだけ1回だけ作る（遅延初期化）」ようにしたいと考え、
`getInstance()` の中で `synchronized`（＝同時に1スレッドしか入れない仕組み）と二重の null チェックを
組み合わせています。Web の複数スレッドから同時に呼ばれる前提です。

対象: `bad/ExchangeRateHolder.java`
「どこが問題か、どう直すべきか」をレビューしてみてください。
