# 【ストック】会員ランク別の送料計算

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

会員ランク（プラチナ / ゴールド / シルバー / ブロンズ）に応じて送料を決める `ShippingFeeCalculator` クラスです。
仕様は「プラチナ会員は送料無料、ゴールド会員は基本送料の半額、シルバー会員は基本送料そのまま」というもの。
`calculate(String rank, int baseFee)` にランク名（文字列）と基本送料を渡すと、その会員が実際に払う送料を返します。

対象: `bad/ShippingFeeCalculator.java`
「どこが問題か、どう直すべきか」をレビューしてみてください。
