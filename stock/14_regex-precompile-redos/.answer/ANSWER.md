## ❌ NGポイント (bad/ 配下)

1. **ループの中で毎回 `Pattern.compile(...)` を呼んでいる（性能）**: `for` の中で `Pattern.compile("^(.+)+@.+$")` を実行している。正規表現のコンパイル（＝パターン文字列を機械が照合に使える形に組み立てる処理）は意外と重く、`Pattern` は「一度作ったら何度でも使い回せる」ように設計されている。それを問い合わせ1件ごとに作り直しているので、大量に届くフォームをさばくほど無駄な組み立て作業が積み上がって遅くなる。`static final` の定数として最初に1回だけコンパイルすべき。

2. **`String.matches(...)` を使っている（性能）**: 電話番号のチェックで `form.getPhone().matches("...")` を呼んでいる。この `String#matches` は、内部で呼ぶたびに `Pattern.compile` → 照合 → 使い捨て、を毎回やっている。つまり1と同じ「毎回コンパイル」の無駄がここでも起きている。使い回す `Pattern` を用意して `matcher(...).matches()` にすべき。

3. **ReDoS を起こす危険なパターンを使っている（セキュリティ）**: メールの `^(.+)+@.+$` は、`(.+)+` という「1文字以上の塊を、さらに1回以上くり返す」入れ子になっている。この形は、`@` を含まない長い文字列を渡されると、区切り方の組み合わせを片っ端から試すバックトラッキング（＝後戻り探索）が爆発的に増え、CPU が張り付いて他の処理まで止まる。これが ReDoS（＝正規表現によるサービス妨害）。悪意ある1件の入力でサーバ全体が固まりうる、地味だが深刻な穴。

4. **入力文字列の長さ上限チェックが無い（セキュリティ）**: `form.getEmail()` をそのまま正規表現に流している。3の危険パターンと組み合わさると、極端に長い入力（例：数万文字の `aaaa...`）を送られたときに後戻り探索の爆発を最大化してしまう。検証の前に「長すぎる入力は問答無用で弾く」ガードが要る。

5. **例外を握りつぶして `true`（有効扱い）で返している（例外処理）**: `try` の中で例外が出ると `catch` で `valid.add(form)` し、不正・壊れたデータを「有効」として通してしまう。しかも `form.getEmail()` などが `null` の場合、`matcher(...)` や `matches(...)` が `NullPointerException` で落ちるのに、それを黙って有効扱いにしている。「何かあったら通す」は検証としては最悪の初期値。異常は握りつぶさず、無効（`false`）として扱うのが安全側の判断。

> 補足：`try` ブロックの中には例外が出る処理（正規表現の照合）が実際には入っておらず、判定は `try` の外で終わっている。つまり握りつぶしのための `catch` が「保険のつもりで安全と逆向きに効いている」状態で、構造としても意図が破綻している。

## ⭕️ 改善案 (good/ 配下)

1. **`Pattern` を `static final` で1回だけコンパイルして使い回す**: `EMAIL_PATTERN` / `PHONE_PATTERN` をクラス直下の定数にし、`matcher(text).matches()` で照合する。ループ内コンパイルも `String#matches` も消える。

2. **バックトラッキングが爆発しない素直なパターンにする**: メールは `^[^@\\s]+@[^@\\s]+\\.[^@\\s]+$`（＝「@と空白以外が1文字以上」を @ で区切る素直な形）にして入れ子のくり返しをなくす。厳密なメール検証が要る場面では、自前の正規表現より Bean Validation の `@Email` など標準の仕組みを使うのも良い。

3. **入力長のガードを入れる**: `MAX_LENGTH`（例：256）を超える入力は正規表現に渡す前に `false` で弾く。万一パターンが重くても被害を抑えられる。

4. **`null` と失敗を明示的に扱う**: `null` は `false`、判定は例外を握りつぶさず素直に返す。「該当0件」でも `null` ではなく空リストを返し、呼び出し側の NPE を防ぐ。

5. **絞り込みは `filter().collect()` で表現する**: 「有効な件だけ集める」を Stream で素直に書き、外部リストへの手動 `add` をやめて意図を明確にする。
