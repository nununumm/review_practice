# 【ストック】会員ポイント履歴クラスの設計

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

会員ごとに、ポイントの獲得や消費といった「イベント」を溜めておき、
今の合計ポイントを計算できる「ポイント履歴（`PointHistory`）」クラスを作りました。
`add` や `size` といったリストの機能をそのまま使えると便利だと思って、
リストを土台にする形で組み立ててあります。合計を出す `totalPoints()` や、
イベントを追加する `addEvent(...)` も自前で足しました。
