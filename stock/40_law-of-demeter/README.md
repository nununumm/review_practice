# 【ストック】配送ラベルの組み立て

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

注文（Order）の情報から、配送ラベルに印字する文字列を組み立てる `ShippingLabelService` です。
ラベルには「郵便番号」「都道府県」「宛名」を載せます。
データ構造は、Order が Customer（顧客）を持ち、その Customer が Address（住所）を持つ、という入れ子になっています。
サービスはこの Order を1つ受け取り、そこから必要な項目を取り出してラベル文字列を返します。

対象: `bad/ShippingLabelService.java`
