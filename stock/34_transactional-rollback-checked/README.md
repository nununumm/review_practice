# 【ストック】ポイント交換処理のトランザクション

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

会員が貯めたポイントを景品と交換する「ポイント交換」機能のサービスです。
処理はシンプルで、まず会員のポイント残高を減らして保存し、そのあとで景品の在庫を1つ減らします。
もし在庫が足りなかったら、業務エラーとして例外を投げて処理を止める仕様です。
なお、メソッドには `@Transactional`（＝一連の処理をまとめて扱うための注釈）を付けてあります。
