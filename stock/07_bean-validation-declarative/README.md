# 【ストック】会員登録リクエストの検証

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

会員登録フォームから送られてくる入力（氏名・メールアドレス・年齢・パスワード）を
受け取り、内容をチェックしてから会員として登録するサービスです。
入力チェックは `RegisterService` の中でおこない、問題がなければ
`MemberRepository` に保存します。管理画面から会員を追加する用の
検証メソッドも用意してあります。

対象: `bad/RegisterService.java`（あわせて `bad/RegisterRequest.java`, `bad/RegisterController.java`）
「どこが問題か、どう直すべきか」をレビューしてみてください。
