# 【ストック】送金内容の検証

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

送金機能の入力チェックを担う `TransferValidator` です。`validate()` で、
送金額が正の数か・振込先口座番号が10桁か・送金額が上限（100万円）以内か、を確認します。
このメソッドは送金 API のサービス層から、実際の送金処理の直前に呼ばれます。
開発環境ではきちんとエラーになることを確認済みですが、本番でも同じように動くか
レビューしてほしい、という依頼です。

対象: `bad/TransferValidator.java`
「どこが問題か、どう直すべきか」をレビューしてみてください。
