# 【ストック】クーポン適用可否の判定

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

ECサイトで、注文時にクーポンを適用できるかどうか（true / false）を判定するサービスです。
会員ランク（GOLD / SILVER / BRONZE）・購入金額・キャンペーン期間・ログイン状態などの条件を組み合わせて、
「このお客さんは、このクーポンを使えるか」を判定します。判定結果は決済画面の「クーポンを使う」ボタンの活性/非活性に使われます。

対象: `bad/CouponEligibilityService.java`
「どこが問題か、どう直すべきか」をレビューしてみてください。
