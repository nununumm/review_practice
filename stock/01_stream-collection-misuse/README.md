# 【ストック】注文明細の集計処理

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

ECサイトの注文集計サービスです。注文（`Order`）と注文明細（`OrderItem`）のリスト、
そして商品マスタ（`Product`）のリストを受け取り、(a) 全注文の合計金額、
(b) 商品カテゴリ別の売上、(c) 一定額以上の「高額注文」の抽出、をまとめて計算して返します。
明細の `productId` から、商品マスタを引いてカテゴリ情報を得ています。
