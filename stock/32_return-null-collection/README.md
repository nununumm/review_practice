# 【ストック】商品照会サービスの戻り値設計

**📅 出題日**: （ストック作成）

## 📋 レビュー課題

ECサイトの商品を照会する `ProductQueryService` です。カテゴリ（例:「文房具」）を指定して商品を一覧で取り出したり、商品コード（例:「A-001」）を指定して1件だけ取り出したりします。
呼び出し側（画面のコントローラーなど）は、返ってきた結果を画面表示のためにそのまま使います。一覧はループで1件ずつ表示し、単体は詳細画面に流し込む、という素朴な使われ方です。
DBアクセス部分は `repository` に任せている想定です。
