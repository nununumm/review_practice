## 📋 レビュー課題

会員登録APIから呼ばれるサービスクラスです。1回の登録で次の4つを行っています。

1. 会員レコードを保存する
2. 新規登録特典のクーポンを付与する（クーポン発行＋会員側のフラグ更新）
