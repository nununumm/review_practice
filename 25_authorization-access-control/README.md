# 第25問：経費精算の承認API

**📅 出題日**: 2026年9月6日

## 📋 レビュー課題

社内の経費精算システムです。社員が経費を申請し、上長がそれを承認すると、経理向けの支払データ（`Payment`）が作られて振込が実行されます。

- `GET /api/expenses/{id}` … 申請の詳細を表示する
- `GET /api/expenses` … 申請一覧を表示する
- `POST /api/expenses/{id}/approve` … 申請を承認する

前提となる社内ルール:

- 経費申請を承認できるのは、**申請者の上長**だけ。
- **10万円を超える申請は部長の承認が必要**。
- ログインは Spring Security で済んでおり、**ログイン中の社員は認証情報から取得できる**状態です。
- `Expense` エンティティには、申請者名・金額のほかに**振込先の銀行口座番号**が入っています。

対象: `bad/ExpenseController.java` / `bad/ExpenseApprovalService.java`

「どこが問題か、どう直すべきか」をレビューしてみてください。
